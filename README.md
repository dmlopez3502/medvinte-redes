# medvinte-redes

Imágenes y videos de las publicaciones de Medvinte en Facebook e Instagram. GitHub Pages los publica para que Metricool los tome al programar cada publicación.

## Cómo está organizado

```
publicaciones/
  AAAA-MM-DD_tipo_tema/      una carpeta por publicación, con la fecha en que sale
    video.mp4 + portada.jpg  reels
    01.jpg, 02.jpg, ...      carruseles, en el orden en que se ven
    imagen.jpg               publicación de una sola imagen
REGISTRO.md                  qué se publicó, cuándo y con qué material
```

Dirección pública de cada archivo:
`https://dmlopez3502.github.io/medvinte-redes/publicaciones/<carpeta>/<archivo>`

No borres ni renombres carpetas de publicaciones ya programadas: Metricool las toma por su dirección.
